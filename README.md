# E-Pharmacy Price Comparison System

The E-Pharmacy Price Comparison System is an interactive web application developed to help users compare medicine prices across multiple online pharmacy platforms. The system retrieves real-time product information and pricing data from online shopping sources, enabling users to identify the most affordable option before making a purchase.

The project was developed using Python, Streamlit, Pandas, Matplotlib, and SerpAPI to create a user-friendly platform for medicine price analysis and comparison.

## 🎯 Project Objectives

* Compare medicine prices from multiple online pharmacies.
* Help users find the lowest-priced medicine option.
* Provide transparent pricing information.
* Visualize price differences through interactive charts.
* Support informed and cost-effective healthcare purchasing decisions.

## 🚀 Key Features

### Medicine Search System

The application allows users to:

* Search medicines by name.
* Retrieve medicine listings from multiple online sources.
* View product details and pricing information.

### Price Comparison Analysis

Interactive comparison of:

* Medicine Prices
* Seller Information
* Product Availability
* Purchase Links

### Best Price Recommendation

The dashboard automatically:

* Identifies the lowest-priced option.
* Highlights the best purchasing choice.
* Helps users save money on medicine purchases.

### Interactive Visualizations

Price Comparison Dashboard includes:

* Bar Chart Analysis
* Pie Chart Distribution
* Company-wise Price Comparison
* Visual Cost Breakdown
